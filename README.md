# Norma DePriest — Professional Portfolio

Static, accessible portfolio for GitHub Pages. The site distinguishes planned research from verified implementation and does not imply Anthropic certification or endorsement.

## Publish

1. Create a **public** repository named `hush1e.github.io` under the `hush1e` account.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
4. Wait for the Pages deployment to finish and open `https://hush1e.github.io/`.

## Before publishing

- Verify all biographical claims and professional titles.
- Replace the GitHub-only contact CTA with your preferred public LinkedIn or contact method if desired.
- Add verified case studies, screenshots, publications, certifications, and outcomes only after checking them.
- Do not upload sensitive employer/student information, secrets, private reports, or unapproved lab data.

No build system, third-party trackers, API keys, or external dependencies are required.
